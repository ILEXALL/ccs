## Сборка iOS

Установлены Flutter 3.47.4, Xcode 26.3, CocoaPods 1.17.0. Для команд из среды агента нужен PATH с `/opt/homebrew/bin`.

Сборка выполняется локально без подписи и без загрузки в TestFlight. Параметр карты берётся из существующего `codemagic.yaml`; файл параметров находится в игнорируемой папке `build/verification/ios-defines.json`.

Проверочная команда:

```sh
PATH="/opt/homebrew/bin:$PATH" /opt/homebrew/bin/flutter build ios --release --no-codesign --no-pub --dart-define-from-file=build/verification/ios-defines.json
```

Последняя проверка завершилась успешно: Xcode собрал `build/ios/iphoneos/Runner.app` (123.6 MB), код завершения 0. Проверены Bundle ID `lv.ilexall.ccs`, версия `1.0.8`, build `4`. Журнал: `build/verification/ios-build.txt`. Это неподписанная проверочная сборка, не IPA для загрузки в TestFlight. Предупреждение о возможности полной миграции с CocoaPods на Swift Packages не блокирует сборку.
